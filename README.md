# 🌱 Nanhi Umang – Child Education Scholarship

## About the Project
Nanhi Umang is an educational initiative focused on supporting underprivileged children by promoting education and scholarship awareness.

## Objectives
- Promote education for every child.
- Spread awareness about scholarship opportunities.
- Encourage community participation.
- Support equal educational opportunities.
